# 图渡 Logo v2

相较 v1，本版把地球上沿略微上提，并在左右上方增加一枚粉红爱心与一个带三个白色点的蓝色对话框。这样既填补深色天空的留白，也强化“表情漂洋渡海、跨语言交流”的含义。

## 推荐用法

- `tudu-logo-1024.png`：社媒主图、长期归档与后续再导出
- `tudu-logo-512.png`：社媒头像、PWA 大图标
- `tudu-logo-256.png`：高分屏网站品牌图标
- `tudu-logo-192.png`：Android / PWA 图标
- `tudu-logo-180.png`：Apple Touch Icon
- `tudu-logo-128.png`：网站左上角展示（高分屏）
- `tudu-logo-64.png`：网站左上角展示或紧凑 UI
- `tudu-logo-48.png`：浏览器快捷方式兼容尺寸
- `tudu-logo-32.png`：标准 favicon
- `tudu-logo-16.png`：最小 favicon

不建议导出 8×8：三枚表情、地球和交流符号会退化成无法稳定识别的色块。

## HTML 示例

```html
<link rel="icon" type="image/png" sizes="32x32" href="/brand/tudu-logo-v2/tudu-logo-32.png" />
<link rel="icon" type="image/png" sizes="16x16" href="/brand/tudu-logo-v2/tudu-logo-16.png" />
<link rel="apple-touch-icon" sizes="180x180" href="/brand/tudu-logo-v2/tudu-logo-180.png" />
```
