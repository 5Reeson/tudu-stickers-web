# 图渡网站字体与视觉评估

日期：2026-08-30

## 审视范围

- 首页桌面端首屏（1440×1000）
- 首页移动端首屏（390×844）
- 当前 CSS 字体栈、字号、字重与中英文混排
- 与图渡像素表情 Logo 的品牌匹配度

## 视觉总览

网站目前以米白网格纸、黑色粗描边、轻微旋转卡片、绿色记号笔划线和贴纸拼贴构成。整体已经建立了“认真做工具，但说话不严肃”的视觉语言。正文与控件使用系统无衬线字体，信息清晰；主要短板是标题、品牌名和正文都来自同一套系统字体，品牌层级还不够鲜明。

## 推荐字体系统

### 首选

- 品牌名、Hero 与主要章节标题：得意黑 Smiley Sans
- 正文、导航、按钮与表单：保留现有 `SF Pro / PingFang SC / system-ui` 字体栈
- 步骤编号、格式名和技术标签：保留 `ui-monospace`

得意黑只用于大字号短文本。它的窄斜结构和手绘美术字细节与网页的涂鸦、贴纸和像素 Logo 相容，但不适合正文或密集 UI。

### 次选

- 标题：阿里妈妈方圆体 VF，采用偏圆但不过分圆润的状态
- 正文：现有系统字体，或 IBM Plex Sans SC

方圆体能在坚实与圆润之间调整，概念上最贴合“工具 + 可爱”；但若计划把字体直接用于可注册商标的标准字，应先再次核对官方下载包中的最新授权条款。

### 保守方案

- 全站继续使用当前系统字体
- 只为“图渡 / TuDu”制作定制字标

这是加载最轻、跨页面最稳定的方式，也能避免彩色 Logo、贴纸插画和个性字体同时竞争。

## 实施建议

- 每个页面最多使用三种角色：展示字体、正文无衬线、等宽标签字体。
- 得意黑仅用于品牌名、H1 和少数 H2；按钮和正文不要使用。
- 当前标题的负字距较大；切换得意黑后应从接近 `0` 的字距重新测试。
- 中文字体应使用 WOFF2，并通过 `unicode-range` 分包或仅加载页面实际需要的字符；同时设置 `font-display: swap`。
- `TuDu` 可跟随得意黑自带拉丁字符；`WhatsApp`、`macOS`、`GitHub` 等正文英文继续跟随系统字体。

## 结论

最适合当前网站的不是全站替换字体，而是：**得意黑负责品牌与情绪，系统字体负责工具信息，等宽字体负责技术标签。**
